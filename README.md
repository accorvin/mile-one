# Mile One 🏃

A native iOS app that coaches beginners through a 9-week Couch to 5K running program.

## What is this?

Mile One combines structured interval training, GPS route tracking, and pre-run route planning in a clean, distraction-free package. It follows the NHS C25K program: 9 weeks, 3 runs per week, 27 sessions total.

## Tech Stack

- **Language:** Swift 6 (strict concurrency)
- **UI:** SwiftUI
- **Storage:** SwiftData + CloudKit
- **Maps:** MapKit
- **Health:** HealthKit
- **Audio:** AVSpeechSynthesizer
- **Location:** CoreLocation (background)
- **Minimum:** iOS 17+
